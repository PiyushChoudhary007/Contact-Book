# Contact-Book
Contact Book using linked lists and file storage. Supports adding, searching, updating, and deleting contacts with alphabetically sorted insertion. Demonstrates self-referential structures and persistent data storage for real-world contact management.

Overview

The Contact Book is a Python project that allows users to store, search, update, and delete contacts. It uses a self-referential linked list for in-memory storage and file persistence to save data across sessions. Contacts are automatically stored in alphabetical order for easy navigation.

Features

 Add Contact – Insert contacts alphabetically.

 Display Contacts – Show all saved contacts in sorted order.

 Search Contact – Find a contact by name.

 Update Contact – Modify phone number or email.

 Delete Contact – Remove a contact from the list.

 Persistent Storage – Contacts are saved in a file (contacts.dat).

 How to Run

Clone the repository:

git clone https://github.com/yourusername/contact-book.git
cd contact-book


Run the program:

python contact_book.py
